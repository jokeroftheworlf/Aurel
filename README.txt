Aurel installable app (PWA)
1. Upload ALL files in this folder to any HTTPS static host (GitHub Pages, Netlify Drop, Cloudflare Pages, Vercel).
2. Open the site on your phone in Chrome, open the menu, tap Install app (or Add to Home screen).
3. After the first load it works offline. Your solves, backgrounds and sounds stay on the device.
